1- O obetivo do projeto é a utilização do bootstrap para a organizção da estética do formulário, mesclando clases do css e do bootstrap.

2-foram utilizados o html, css, js e bootstrap.

3-tipos de input:
text= area de texto basicos,
email= área onde se coloca o email do usuário,
password= área onde se coloca a senha do usuário,
number= onde se coloca apenas numeros,
tel= onde se coloca o numero de telefone do usuário,
url= onde se coloca um link do usuário,
search= onde se procura coisas especificas como palavras-chave,
date-month,week= onde são adicionados as datas que serão informadas,
time=onde são adicionados o tempo que será informados,
datetime-local= mesclagem de data e hora,
color= onde se adiciona uma cor escolhida de destaque,
range= barra de ecolha de ponto especificos,
file= onde se adiciona um arquivo do computador,
checkbox= caixas de escolha de informações, 
radio= botão de opção selecionáveis,
hidden= são informações que não aparecem para o usuário,
submit= botão de envio do formulario,
reset= botão de limpar as áreas do formulario,
button= área de funcionamento de um botão,
image= serve para criar um botão visualmente melhor.
